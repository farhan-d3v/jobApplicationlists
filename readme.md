# Job Application Tracker

A web application built with **Python, Django, and MySQL** to help users manage and track their job applications in one place.

## Features
- **Create:** Add new job applications.
- **Read:** View saved applications and their details.
- **Update:** Edit existing application information.
- **Delete:** Remove applications with a confirmation page.
- **Status Tracking:** Track application statuses such as Applied, Interview, Selected, and Rejected.

## Tech Stack
- Python
- Django
- MySQL
- HTML
- Django Templates

## Purpose
This project was developed to practise Django web development, database integration, form handling, URL routing, and CRUD operations.
